MAHESWARI PORTFOLIO WEBSITE

1. Extract the ZIP file.
2. Open the folder.
3. Double-click index.html to preview the portfolio in your browser.
4. To publish it online, upload index.html to GitHub Pages, Netlify, or another static website host.

Notes:
- The portfolio uses Font Awesome icons and Google Fonts via CDN.
- Project images are loaded from Unsplash, so an internet connection is needed to display them.
- The contact form opens the visitor's email app with a pre-filled message; it does not send messages through a server.
- Replace the initials avatar with your own photo whenever you are ready.
- Please verify the LinkedIn profile URL before publishing.
